# Calibre job card

A ChatGPT card is a JSON file named `cards/<pushId>.calibrejob`.

Required: `type` = `calibrejob`, `pushId` (unique slug), `watchName`.

The one-tap link is:

https://samjohnmullan-create.github.io/CalibreOI/?card=<pushId>

Put that URL in the card as `importUrl`. The file must be in this repo before the link works.
