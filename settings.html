First-time database setup

Run this once in Supabase → SQL Editor. It creates one private Calibre state row per signed-in user and enables Row Level Security.

Do not create an anonymous/public policy. Your publishable key is public by design; your signed-in session plus RLS controls access to the data.

How sync works

Calibre still saves locally first. When you are signed in, it also pushes the state to Supabase. Opening Calibre on another signed-in device pulls the cloud state and merges watches using their update timestamps.

Version 1 still stores compressed photos inside the job data. We can move photos into Supabase Storage next so cloud records stay small and photo syncing scales better.
