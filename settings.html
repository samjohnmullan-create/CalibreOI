Two ways in

Proxy: deploy this folder to Vercel and set XAI_API_KEY. Optional AI_BASE_URL and AI_MODEL. The function is api/ai.js.

Direct: any OpenAI-compatible endpoint. Grok is https://api.x.ai/v1. A local model is usually http://localhost:11434/v1 if it speaks that API. Browser calls can be blocked by CORS — if the test fails that way, use the proxy.
